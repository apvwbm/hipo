## Qué hace

- **Cuánto te puedes permitir**, con tus ingresos, deudas y ahorros.
- **Lo que cuesta de verdad cada casa**: impuestos de tu comunidad, gastos, entrada y cuota.
- **Visitas** con lista de qué mirar y preguntar, tu nota y fotos.
- **Ofertas de los bancos** ordenadas por coste real, y si cada producto vinculado compensa.
- **Papeles** que pide el banco: cuáles faltan y cuáles han caducado.
- **Plazos y avisos**: arras, tasación, FEIN, notario, firma e impuestos.
- **Una guía en seis fases** que te dice qué toca en cada momento.

Pensada para el proceso español: solo en castellano y en euros.

## Privacidad

Todo se guarda cifrado en tu móvil y la app no tiene permiso de internet. Tus documentos se
quedan donde están; HIPO solo los enlaza. Sin cuentas, anuncios ni rastreo.

## Instalar

Descarga `hipo.apk` desde [la última versión](https://github.com/apvwbm/hipo/releases/latest)
y ábrelo en el móvil. Para actualizar, instala el nuevo encima: tus datos se conservan.

<details>
<summary>Para desarrolladores</summary>
<br />

Expo SDK 57 · React Native · TypeScript · SQLite cifrada con SQLCipher.

```bash
npm install && npm start   # Expo Go
npm run verifica           # tests de la lógica
npm run apk                # APK en el Escritorio (Windows + Android SDK)
```
